# ♠ Poker Tracker

Небольшой бесплатный трекер покерных сессий для iPhone. Работает без сервера и без базы данных в облаке — все данные хранятся **только на вашем iPhone**.

## Возможности

- Ввод бай-ина и кешаута → автоматический расчёт результата сессии
- Общий баланс за все сессии + статистика (сессии, победы, поражения, средний результат)
- История всех игр с фильтрами: все / этот месяц / победы / поражения
- Редактирование и удаление сессий
- **Экспорт** резервной копии в файл (JSON) и **импорт** обратно — защита от потери данных при удалении приложения системой iOS
- Запускается с иконки на рабочем столе, как полноценное приложение (standalone-режим)
- Работает офлайн (Service Worker кэширует приложение)

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Всё приложение (интерфейс + логика) |
| `manifest.webmanifest` | Настройки PWA (иконка, режим окна) |
| `sw.js` | Офлайн-режим |
| `icon-*.png` | Иконки приложения (180/192/512 px) |

## Установка на iPhone без Mac и без Xcode

iOS разрешает установить веб-приложение на рабочий стол только с HTTPS-адреса. Поэтому файлы нужно разместить на **бесплатном статическом хостинге** (это не сервер: данные приложения всё равно остаются на телефоне).

### Способ 1 — GitHub Pages (рекомендуется, бесплатно)

1. Создайте репозиторий на [github.com](https://github.com/new), например `poker-tracker`, публичный.
2. Загрузите в него файлы: `index.html`, `manifest.webmanifest`, `sw.js`, `README.md`, `icon-180.png`, `icon-192.png`, `icon-512.png`.
3. В настройках репозитория: **Settings → Pages → Source: Deploy from a branch → Branch: main → / (root) → Save**.
4. Через минуту приложение будет доступно по адресу:
   `https://<ваш-логин>.github.io/poker-tracker/`

### Способ 2 — Netlify Drop (без регистрации)

1. Откройте [https://app.netlify.com/drop](https://app.netlify.com/drop)
2. Перетащите папку `poker` целиком в браузер.
3. Получите случайный адрес вида `https://xxxxx.netlify.app`.

### Установка иконки на рабочий стол iPhone

1. Откройте адрес приложения в **Safari** (только в Safari — из других браузеров не получится).
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой внизу).
3. Выберите **«На экран “Домой”»** → **«Добавить»**.

Готово — появится иконка, приложение открывается на весь экран без адресной строки и работает офлайн.

## Резервная копия

- **Экспорт**: кнопка «⬇︎ Экспорт» сохранит JSON-файл со всеми сессиями (в «Файлы» на iPhone). Положите его в iCloud Drive для надёжности.
- **Импорт**: кнопка «⬆︎ Импорт» выберет файл и предложит **объединить** данные с текущими или **заменить** историю целиком.

Рекомendуйте делать экспорт после каждой заметной серии сессий — это защитит статистику, даже если iOS удалит данные при нехватке места.

## Обновление

Приложение обновляется автоматически: при каждом открытии Service Worker проверяет свежую версию на сервере. Если что-то пошло не так — очистите кэш в Safari (Настройки → Safari → История и данные сайтов) и откройте адрес заново.

## Разработка локально

python -m http.server 8777
